# Crescendo 🎧

Tienda de audio en línea (audífonos, parlantes y accesorios) hecha con PHP bajo el patrón MVC y MySQL. Los productos, categorías, beneficios y testimonios se leen desde la base de datos, y el formulario de contacto guarda los mensajes en ella.

## Tecnologías
- PHP (MVC: `models`, `views`, `controllers`) con PDO
- MySQL / MariaDB
- Bootstrap (cuadrícula) y CSS propio
- Swiper (carrusel de testimonios)
- Font Awesome (íconos)

## Funcionalidades
- Diseño responsive (celular y computador)
- Carrusel de testimonios
- Efectos hover y animaciones
- Botón flotante de WhatsApp
- Formulario de contacto con página de agradecimiento
